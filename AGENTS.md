# RemoteCam — agent handbook

The handbook lives in **[CLAUDE.md](CLAUDE.md)**. Read that instead of this file, along
with [PLAN.md](PLAN.md) for the design and milestones and
[docs/protocol.md](docs/protocol.md) for the wire format. Per-platform detail is in
`windows/CLAUDE.md` and `ios/CLAUDE.md`.

This file exists only so agents that look for `AGENTS.md` by convention find their way
there. It deliberately holds no content of its own: it used to be a copy of
`CLAUDE.md` and had already drifted on which milestones were done and which
per-platform files exist. Two handbooks that disagree are worse than one.
